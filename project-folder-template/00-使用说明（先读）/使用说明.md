# 使用说明（先读）

## 如何用于新项目

1. 复制整个 `project-folder-template` 目录到你的工作区。
2. 将复制后的文件夹改名为项目名（或「项目名-PM」等约定）。
3. 先阅读本说明与 `mindmaps/` 中的体系图（若仓库中有）。
4. 按阶段 `01`–`10` 推进；`11`、`12` **贯穿全程**同步维护。
5. 临时材料先放 `99`，定期清理或归入正式阶段目录。

## 章节与文件夹对应

| 章节 N | 文件夹 |
|--------|--------|
| 0 | `00-使用说明（先读）` |
| 1–12 | `01` … `12` 对应主题目录 |
| — | `99-本项目其他` |

阶段编号与文件夹前缀一致：第 N 章 → `0N-…`（两位数）。

## 文件命名约定

- **模板-**：可填写的结构化文档骨架（如一页纸、周报、会议纪要）。
- **清单-**：检查项或登记表（勾选、跟踪、闭环）。
- **本阶段说明.md**：该阶段目的、建议动作、产出与完成标准。

复制模板后可去掉前缀或按项目约定改名，但建议保留语义清晰的中文名。

## 贯穿阶段

- **11 变更与风险管理**：立项起即建立风险/问题登记，全程更新。
- **12 沟通会议与周报**：例会、纪要、周报按节奏产出，不限于某一阶段末。

## 建议节奏

开项目时：读 00 → 填 01 一页纸与裁剪表 → 同步建 11/12 空表 → 再按 02–10 推进。
